# Pain

Arguments: what hurts, in free text. Write the entry in `NATIVE_LANGUAGE`.

1. Add one line to the "Pain log" in `PLANKS.md`: date, the plank it points to, severity (1 annoying, 2 slows me down, 3 blocks me or is risky) and the text.
2. If the plank is ambiguous, ask ONE question to pick it. Do not interview further.
3. If the same plank already has two or more open pains, say so and suggest `swap` for it.
4. Do not change code, do not open a spec. The log exists so the next swap is chosen by real pain, not by guess.
